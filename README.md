# Rateio-ES

O projeto é um sistema colaborativo para rateio e gestão de despesas em grupo. Nele, os usuários podem registrar gastos, adicionar contribuintes e ter a divisão automática dos valores. A plataforma inclui um painel de controle para acompanhar pagamentos pendentes e quitados, simplificando a organização financeira conjunta.

## Estrutura do Repositório

```
Rateio-ES/
├── docs/   # Documentação do projeto (arquitetura, guias, decisões, etc.)
├── src/    # Código-fonte da aplicação
└── README.md
```

## Seções

### 📄 Documentação ([`docs/`](./docs/))

Contém toda a documentação do projeto: arquitetura, guias de uso, decisões técnicas e demais recursos de referência.

### 💻 Código-Fonte ([`src/`](./src/))

Contém o código-fonte da aplicação, organizado em módulos e pacotes conforme o desenvolvimento avançar.

## Como Contribuir

1. Para adicionar documentação, crie ou edite arquivos `.md` dentro da pasta `docs/`.
2. Para contribuir com código, adicione seus arquivos dentro da pasta `src/`.
3. Mantenha este `README.md` atualizado sempre que a estrutura do projeto mudar.
